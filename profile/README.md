# sslTrus

Tools and integrations for sslTrus remote code signing.

## Projects

| Project                                                                      | Description                                                                            |
|------------------------------------------------------------------------------|----------------------------------------------------------------------------------------|
| [Code Sign Action](https://github.com/ssltrus-official/code-sign-action)     | Sign files in GitHub Actions workflows on Linux, macOS, and Windows.                   |
| [Code Sign API for Go](https://github.com/ssltrus-official/code-sign-api-go) | Integrate certificate queries, hash signing, and signing records into Go applications. |
| [Homebrew Tap](https://github.com/ssltrus-official/homebrew-tap)             | Install the code signing CLI and desktop application on macOS.                         |

## Get started

- **GitHub Actions:** add Code Sign Action to your build and release workflow.
- **Go applications:** use Code Sign API for Go to integrate with the remote signing API.
- **macOS:** install the CLI or desktop application through Homebrew.

Each project provides documentation in English and Simplified Chinese.
